# Template de Bot de Visão

Este diretório serve como template oficial para o gerador de scaffolds (`sdk/tools/create_bot.py`).

## Estrutura:
- `bot.json`: Manifesto de capacidades e metadados.
- `config.py`: Configurações padrão.
- `strategy.py`: Lógica de tomada de decisão.
- `main.py`: Ponto de entrada compatível com o Bot SDK.
- `tests/`: Testes unitários da estratégia.
