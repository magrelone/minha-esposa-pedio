# MM2 Coin Collector

Bot automatizado para **Roblox — Murder Mystery 2** adaptado para o Bot SDK.

## Capacidades:
- Detecção de moedas douradas padrão (`yolo_coin_m_v3.pt`).
- Detecção de jogadores e moedas de evento com manobra de fuga (`yolo_coin_person_m_v2.pt`).
- Navegação espacial baseada em offset de tela relativo à posição do personagem.
- Failsafe automático de liberação de teclas.
