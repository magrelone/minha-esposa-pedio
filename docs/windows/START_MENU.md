# Start Menu Studio — Especificação Técnica & Menu Híbrido (Win 7 + Win 11)

## 1. O Conceito da Fusão Híbrida (Windows 7 + Windows 11)
A fusão do Windows 7 com o Windows 11 une o melhor de duas eras do Windows:
1. **Estrutura de 2 Colunas do Windows 7:**
   - **Coluna Esquerda:** Aplicativos fixados, mais usados, lista de programas e busca.
   - **Coluna Direita:** Atalhos diretos para a pasta pessoal do usuário, Documentos, Imagens, Músicas, Downloads, Este Computador, Painel de Controle e Configurações.
2. **Estética Fluent Glass do Windows 11:**
   - Efeito Acrylic/Mica com desfoque profundo translúcido.
   - Cantos arredondados modernos (Border Radius 24px).
   - Campo de pesquisa global no topo e rodapé com perfil do usuário e botão de energia.

## 2. Padrão Universal de Desfazer
Qualquer alternância de layout (Híbrido, Windows 11 Fluent, Windows 10, Windows 7 Clássico) registra snapshot imediato no histórico com botão "↩️ Desfazer" e botão "Restaurar Menu Iniciar Original".
