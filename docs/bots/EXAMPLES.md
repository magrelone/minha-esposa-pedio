# Exemplos e Casos de Estudo (EXAMPLES.md)

Esta pasta contém exemplos detalhados de integração de bots para servir de modelo tanto para desenvolvedores quanto para agentes de inteligência artificial.

---

## Exemplos Disponíveis:

1. **[Roblox MM2 Coin Collector (Caso Real)](file:///c:/Projetos/Minha%20Esposa%20Pedio/docs/bots/examples/mm2-coin-collector.md)**:
   - Integração completa ponta a ponta do projeto upstream `andrewwongwong/RobloxBot`.
   - Demonstra uso do `LegacyYoloV5MM2Provider`, captura de janela, evasão de jogadores e coleta de moedas.

2. **[Teddy Collector (Caso Didático para IA)](file:///c:/Projetos/Minha%20Esposa%20Pedio/docs/bots/examples/teddy-collector.md)**:
   - Demonstração conceitual completa de como um agente IA deve planejar, registrar e estruturar um bot novo para encontrar ursinhos de pelúcia em um jogo hipotético.
   - Enfatiza a não-invenção de modelos e o fluxo de `MODEL_REQUIRED`.
